# AutoParts Marketplace

Учебный проект по созданию микросервисной системы продажи автозапчастей.

## Цель
Освоить production-ready практики разработки на Java: Spring Boot, Kafka, Docker, Observability, Distributed Transactions.

## Технологии
- Java 17, Spring Boot 3.4, Gradle
- Keycloak, JWT, OAuth2
- PostgreSQL, Redis, Kafka, Elasticsearch, MinIO
- Liquibase (YAML для master changelog, SQL для миграций)
- Docker Compose, GitLab CI, Prometheus, Grafana, Tempo
