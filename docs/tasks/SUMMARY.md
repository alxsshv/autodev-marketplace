## Ключевые требования
1. Все таблицы ролей (auth.roles, auth.permissions, auth.role_permissions) должны быть удалены
2. Роли хранятся только в Keycloak и передаются в JWT токене
3. Все endpoints должны быть защищены согласно RBAC
4. Revoked tokens хранятся только в Redis (Redis-only подход)
5. Весь код должен быть покрыт тестами (>= 80%)
6. Вся документация должна быть обновлена
