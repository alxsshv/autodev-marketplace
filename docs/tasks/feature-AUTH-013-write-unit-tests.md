# Техническое задание: Написание модульных тестов для AuthService

## Название задачи
Написать модульные тесты для AuthService (AUTH-013)

## Название ветки
feature/AUTH-013-write-unit-tests

## Описание
Необходимо написать модульные тесты для AuthService с моками репозиториев и других зависимостей.

## Цель задачи
Написать модульные тесты для всех методов AuthService с использованием Mockito.

## Критерии выполнения

- [ ] Создан тест `AuthServiceTest` с аннотацией `@ExtendWith(MockitoExtension.class)`

- [ ] Написаны тесты для `login()`:
  - Успешная аутентификация пользователя
  - Обработка неверного email
  - Обработка неверного пароля
  - Обработка заблокированного пользователя (enabled=false)
  - Тест маппинга ролей из Keycloak в JWT

- [ ] Написаны тесты для `refresh()`:
  - Успешное обновление токена
  - Обработка неверного refresh token
  - Обработка истекшего refresh token

- [ ] Написаны тесты для `logout()`:
  - Успешный logout с добавлением в Redis blacklist
  - Проверка вызова методов кэширования

- [ ] Написаны тесты для `getCurrentUser()`:
  - Получение текущего пользователя из Redis кэша
  - Обработка отсутствия пользователя в кэше

- [ ] Написаны тесты для `getKeycloakPublicKeys()`:
  - Получение публичных ключей из Keycloak
  - Обработка ошибок HTTP запроса

- [ ] Написаны тесты для `syncUser()`:
  - Обработка события `user_created`
  - Обработка события `user_updated`
  - Обработка события `user_enabled`
  - Обработка события `user_disabled`
  - Обработка неизвестного события

- [ ] Все тесты используют `assertThat` (AssertJ) для проверок

- [ ] Покрытие модульными тестами >= 90%

- [ ] Добавлены Javadoc комментарии для всех тестов
