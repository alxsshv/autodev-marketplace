# Задача 003.2: Реализовать распределённый Rate Limiting в API Gateway с Redis и Resilience4j

**Статус:** Нужно реализовать

**GitLab задача:** #206 (https://alxsshv.com/Alxsshv/autodev-marketplace/-/work_items/206)

**Ветка:** `feature/003-2-api-gateway-rate-limiting-filter`

---

## Цель:

Реализация распределённой системы ограничения запросов в API Gateway с использованием Redis в качестве хранилища состояний для защиты от DoS-атак и злоупотреблений.

## Описание

***Архитектура решения***

- RedisTemplate для работы с Redis
- Lua-скрипт для атомарной обработки лимитов
- Micrometer для экспорта метрик
- StringRedisSerializer для сериализации данных

---

## Технические требования
Конфигурация

Параметры настраиваются в application.yml:

ratelimiter:
    limit-per-ip: 100
    window-seconds: 60
redis:
    host: localhost
    port: 6379


## Дополнительные параметры при необходимости

***Основные компоненты***

- RateLimitingFilter как GlobalFilter
- Lua-скрипт для обработки лимитов
- Метрики через Micrometer
- IP-извлечение из заголовков

## Функциональные требования

***Ограничение запросов***

- Лимит 100 запросов в минуту на IP
- Использование Redis для хранения состояния
- Атомарная обработка через Lua-скрипт

***Обработка превышения лимита***

- Возврат HTTP 429 статуса
- Заголовок Retry-After с временем ожидания
- Логирование событий

***Исключения***

- Пути /health и /actuator/ не лимитируются
- Fail-open режим при ошибках Redis

## Метрики и мониторинг

- Экспорт метрик в Prometheus
- Отслеживание превышений лимита
- Статистика по IP-адресам

## Тестирование

- Интеграционные тесты с Redis
- Проверка распределённого лимита
- Валидация Retry-After
- Тестирование исключённых путей
- Проверка fail-open режима

---

## Критерии выполнения

- Корректная работа лимита на IP
- Верный возврат 429 статуса
- Правильная работа Retry-After
- Исключённые пути работают без ограничений
- Метрики доступны в Prometheus
- Тесты проходят стабильно
- Распределённый лимит работает корректно
- Fail-open режим функционирует
