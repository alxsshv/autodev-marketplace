# Глоссарий терминов Auth Service

## Базовые термины

| Термин | Описание |
|--------|----------|
| **JWT** (JSON Web Token) | Открытый стандарт (RFC 7519) для создания токенов доступа, представляющих собой JSON-объект, который может быть подписан и зашифрован. |
| **RS256** | Алгоритм подписи JWT, использующий RSA с SHA-256. Требует пару ключей (публичный и приватный). |
| **Access Token** | Токен с коротким сроком жизни (15 минут в MVP), используемый для аутентификации запросов. |
| **Refresh Token** | Токен с долгим сроком жизни (7 дней в MVP), используемый для получения новой пары токенов без повторного ввода пароля. |
| **Keycloak** | Решение с открытым исходным кодом для управления идентификацией и доступом (IAM), реализующее OAuth2 и OpenID Connect. |
| **OIDC** (OpenID Connect) | Протокол аутентификации поверх OAuth 2.0, добавляющий слой идентификации пользователя. |
| **Admin API** | REST API Keycloak для программного управления пользователями, ролями, клиентами и т.д. |

## Технические термины

| Термин | Описание |
|--------|----------|
| **Spring Security** | Модуль Spring Framework для обеспечения безопасности приложений (аутентификация, авторизация). |
| **JwtAuthenticationFilter** | Кастомный фильтр Spring Security для извлечения и валидации JWT токена из заголовка `Authorization`. |
| **@PreAuthorize** | Аннотация Spring Security для декларативной защиты методов на основе ролей или выражений. |
| **Testcontainers** | Библиотека для запуска изолированных интеграционных тестов в Docker контейнерах. |
| **Liquibase** | Инструмент управления версиями базы данных для миграций (аналог Maven/Gradle для DB). |
| **Redis** | NoSQL хранилище данных в памяти, используемое для кэширования, счётчиков rate limiting, списков отозванных токенов. |

## Сущности и модели

| Термин | Описание |
|--------|----------|
| **User** | Пользователь системы с email, ролями, связью с Keycloak ID и Platform Profile. |
| **Role** | Роль пользователя (BUYER, SELLER, MODERATOR, ADMIN). |
| **TokenPair** | Пара токенов (access_token, refresh_token) возвращаемая при входе. |
| **Platform Profile** | Профиль пользователя в сервисе Platform (store_name, verification_status, loyalty_balance). |
| **OAuth Provider** | Внешний провайдер аутентификации (keycloak, google, github) с привязанным аккаунтом. |

## События и Kafka

| Термин | Описание |
|--------|----------|
| **Event** | Асинхронное уведомление о событии в системе (например, `auth.user_authenticated`). |
| **Kafka Producer** | Компонент, публикующий события в Kafka topic (например, `AuthEventProducer`). |
| **Kafka Consumer** | Компонент, подписывающийся на события из Kafka topic. |
| **Consumer Group** | Группа подписчиков для распределенной обработки сообщений (в MVP: `auth-service-events`). |

## Инфраструктурные термины

| Термин | Описание |
|--------|----------|
| **Health Check** | Эндпоинт `/actuator/health` для проверки состояния зависимостей (Redis, Keycloak, PostgreSQL). |
| **Metrics** | Метрики производительности, доступные через `/actuator/prometheus`. |
| **Rate Limiting** | Ограничение количества запросов к endpoint за определенный период времени. |
| **Revoked Token** | Токен, который был отозван (logout или подозрение на компрометацию) и больше не валиден. |

## Методы и операции

| Термин | Описание |
|--------|----------|
| **SETNX** (SET if Not eXists) | Атомарная операция Redis для создания ключа только если он не существует (используется для одноразовых refresh tokens). |
| **INCR** | Атомарная операция Redis для увеличения значения на 1 (используется для счётчиков rate limiting). |
| **TTL** (Time To Live) | Время жизни ключа в Redis, после которого он автоматически удаляется. |
| **MDC** (Mapped Diagnostic Context) | Механизм Logback для добавления контекстных данных в логи (используется для маскировки Authorization заголовка). |

## Структуры ключей Redis

| Ключ | Описание | TTL |
|------|----------|-----|
| `revoked:access:{token_hash}` | Отозванный access token | 15 мин |
| `revoked:refresh:{token_hash}` | Отозванный refresh token | 7 дней |
| `used_refresh:{jti}` | Использованный refresh token (одноразовый) | 7 дней |
| `cache:revoked_check:{hash}` | Кэш результатов проверки revoked | 1 мин |
| `cache:public_key` | Публичный ключ Keycloak для валидации RS256 | 1 час |
| `rate:login:{ip}:{5min_window}` | Счётчик попыток входа по IP | 5 мин |
| `rate:link:{user_id}:{10min_window}` | Счётчик привязки провайдера | 10 мин |
| `rate:admin:{user_id}:{1min_window}` | Счётчик админ-запросов | 1 мин |

## API Endpoints

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/api/v1/auth/login` | POST | Вход пользователя (возвращает пару токенов) |
| `/api/v1/auth/refresh` | POST | Обновление пары токенов по refresh_token |
| `/api/v1/auth/logout` | POST | Выход пользователя (отзывает токены) |
| `/api/v1/auth/me` | GET | Информация о текущем пользователе |
| `/api/v1/auth/validate-token` | GET | Проверка токена (для API Gateway) |
| `/api/v1/auth/external/link` | POST | Привязка OAuth2 аккаунта |
| `/api/v1/auth/external/unlink` | POST | Отвязка OAuth2 аккаунта |
| `/api/v1/auth/external/providers` | GET | Список привязанных провайдеров |
| `/api/v1/admin/users` | GET/POST | Список/создание пользователей (ADMIN only) |
| `/api/v1/admin/users/{id}/roles` | PATCH | Обновление ролей пользователя (ADMIN only) |

---

## Примечания

- Все термины на английском (как в проекте)
- Ключевые компоненты: Redis для revoked tokens и rate limiting, Keycloak для OIDC, PostgreSQL для структурированных данных
- JWT используется RS256 (не HS256) для безопасности — приватный ключ хранится в Keycloak, публичный кэшируется в Redis
- Все операции с Redis атомарны (SETNX, INCR, EXPIRE) для корректной работы при конкурентных запросах
