# Техническое задание: Написание интеграционных тестов для AuthController

## Название задачи
Написать интеграционные тесты (AUTH-012)

## Название ветки
feature/AUTH-012-write-integration-tests

## Описание
Необходимо написать интеграционные тесты для AuthController, чтобы проверить корректность работы всех endpoints.

## Цель задачи
Написать интеграционные тесты для всех endpoints с использованием @SpringBootTest и Testcontainers.

## Критерии выполнения

- [ ] Создан тест `AuthControllerTest` с аннотацией `@SpringBootTest`

- [ ] Написаны тесты для `POST /login`:
  - Позитивный сценарий (успешный логин)
  - Негативный сценарий (неверный email)
  - Негативный сценарий (неверный пароль)
  - Сценарий (заблокированный пользователь)

- [ ] Написаны тесты для `POST /refresh`:
  - Позитивный сценарий (успешное обновление)
  - Негативный сценарий (неверный refresh token)

- [ ] Написаны тесты для `POST /logout`:
  - Успешный logout с валидным токеном
  - Попытка logout с невалидным токеном (401)

- [ ] Написаны тесты для `GET /me`:
  - Получение текущего пользователя с валидным токеном
  - Попытка получения с невалидным токеном (401)

- [ ] Написаны тесты для `GET /keys`:
  - Получение публичных ключей Keycloak

- [ ] Написаны тесты для `POST /sync`:
  - Обработка события `user_created`
  - Обработка события `user_updated`
  - Обработка события `user_enabled`
  - Обработка события `user_disabled`
  - Обработка неверного события (400)

- [ ] Все тесты используют Testcontainers для PostgreSQL и Redis

- [ ] Покрытие интеграционными тестами >= 80%

- [ ] Все тесты проходят успешно в CI/CD
