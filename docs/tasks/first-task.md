# Первая задача: Настройка локального окружения

## Цель
Подготовить рабочее окружение для разработки микросервисного приложения AutoDev Marketplace.

## Задача
Настройте локальное окружение согласно следующим шагам:

1. Установите необходимые инструменты:
   - Java 17 (рекомендуется OpenJDK)
   - Gradle 8.x
   - Docker 20.x
   - Docker Compose 2.x
   - Git 2.30+
   - IntelliJ IDEA 2023.x (или другой IDE по выбору)

2. Проверьте установку инструментов, выполнив в терминале:
```bash
java -version
gradle -version
docker --version
docker-compose --version
git --version
```

3. Клонируйте репозиторий проекта:
```bash
git clone http://192.168.0.162/autodev-marketplace.git
cd autodev-marketplace
```

4. Изучите структуру проекта, ознакомьтесь с файлами:
   - `build.gradle.kts` - основная конфигурация Gradle
   - `settings.gradle.kts` - настройки проекта
   - `docker-compose.yaml` - конфигурация инфраструктуры
   - `docs/` - документация проекта

5. Запустите инфраструктуру проекта:
```bash
docker-compose up -d
```

6. Проверьте, что все контейнеры запущены:
```bash
docker-compose ps
```

7. Ознакомьтесь с документацией проекта:
   - `docs/architecture/system-overview.md` - обзор архитектуры системы
   - `docs/roles/architector.md` - роль архитектора
   - `docs/roles/mentor.md` - роль ментора
   - `docs/study_plan.md` - учебный план

## Критерии успешного выполнения
- Все необходимые инструменты установлены и доступны в командной строке
- Репозиторий успешно склонирован
- Инфраструктура запущена и все контейнеры работают
- Вы ознакомились с основной документацией проекта
- Вы понимаете общий контекст системы и учебного плана
