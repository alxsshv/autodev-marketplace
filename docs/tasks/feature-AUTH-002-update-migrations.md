# Техническое задание: Обновление миграций (удаление ссылок на удаленные таблицы)

## Название задачи
Обновить миграции (AUTH-002)

## Название ветки
feature/AUTH-002-update-migrations

## Описание
После удаления таблиц ролей (AUTH-001) необходимо обновить миграции, чтобы удалить ссылки на удаленные файлы миграций и удалить сами файлы миграций для таблиц, которые больше не нужны.

## Цель задачи
Очистить миграции от ссылок на удаленные таблицы ролей и удалить соответствующие файлы миграций.

## Критерии выполнения

- [ ] Удалены следующие файлы миграций из `v1.0.0/`:
  - `07-06-2026-create-table-permissions.sql`
  - `07-06-2026-create-table-role-permissions.sql`
  - `07-06-2026-create-table-roles.sql`
  - `07-06-2026-insert-initial-roles.sql`
  - `07-06-2026-insert-initial-admin-user.sql`

- [ ] Обновлен master changelog (`db.changelog-master.yaml`) - удалены ссылки на вышеуказанные файлы

- [ ] Проверено, что в application.yml нет ссылок на удаленные конфигурации

- [ ] Выполнена проверка миграций через Liquibase (тест с запуском приложения)
