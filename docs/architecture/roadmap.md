**Версия документа:** 1.1  
**Дата создания:** 2026-06-03  
**Последнее обновление:** 2026-06-04

---

## Обзор

Эта дорожная карта описывает эволюцию архитектуры AutoDev Marketplace от текущего состояния (базовая инфраструктура) до полноценной микросервисной системы для продажи автозапчастей.

**MVP Architecture (8 сервисов):**
- **api-gateway** — единая точка входа
- **auth-service** — аутентификация и авторизация  
- **catalog-service** — каталог, цены, наличие (Products+Prices+Availability)
- **order-service** — заказы, доставка, возвраты (Orders+Delivery+Returns)
- **search-service** — полнотекстовый поиск
- **payment-service** — обработка платежей
- **communication-service** — уведомления и сообщения (Notifications+Messaging)
- **platform-service** — платформенные функции (Users+Moderation+Reviews+Analytics+Admin)

---

## Текущее состояние (T0)

### Реализовано
- ✅ **Инфраструктура:** Docker Compose с полным стеком (PostgreSQL, Redis, Kafka, Consul, Prometheus, Grafana, Loki, Tempo)
- ✅ **API Gateway:** Spring Cloud Gateway с базовой маршрутизацией (частично)
- ✅ **Auth Service:** Базовая аутентификация с Keycloak (частично)
- ✅ **Service Discovery:** Consul для обнаружения сервисов
- ✅ **Мониторинг:** Prometheus, Grafana, Loki, Tempo для наблюдаемости

### Не реализовано
- ❌ Основные бизнес-сервисы (User, Catalog, Order, Payment и др.)
- ❌ Асинхронная коммуникация через Kafka
- ❌ Миграции базы данных
- ❌ Документация API (OpenAPI)
- ❌ CI/CD пайплайны

## Риски и отклонения

### Внутренние риски
- **Задержки в разработке:** Буфет 20% времени на каждый этап
- **Технический долг:** Резервирование времени на рефакторинг
- **Кадровые изменения:** Документирование всех решений (ADR)

### Внешние риски
- **Интеграция с внешними системами:** Задержки в API第三方 сервисов
- **Изменение требований:** Гибкий подход, частые релизы
- **Безопасность:** Аудит на каждом этапе
