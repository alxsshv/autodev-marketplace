# AutoDev Marketplace — Основные бизнес-функции (MVP)

**Версия документа:** 1.2  
**Дата создания:** 2026-06-21  
**Дата обновления:** 2026-06-21  
**Статус:** MVP — только критический базовый функционал

---

## Предисловие

Этот документ содержит **минимальный перечень** бизнес-функций AutoDev Marketplace для MVP (Minimum Viable Product).

**Философия MVP:** Делаем только то, без чего система не может работать. Всё остальное — после первого релиза.

### Что убрано (не для MVP):

| Категория | Убранные функции | Причина |
|-----------|------------------|---------|
| **Поиск** | Автодополнение, история поиска, избранное | Усложнение логики поиска |
| **Профили** | Верификация аккаунта | Будущая фича |
| **Объявления** | Массовая загрузка, управление фото, статистика | Усложнение управления товарами |
| **Коммуникация** | Шаблоны ответов, запросы уточнения, видеозвонки, история переписки | Не критично для первой сделки |
| **Оформление заказа** | Расчёт стоимости доставки, эскроу, интеграция с банками | Доступно только через выбор ТК, без эскроу и интеграций |
| **Доп. сервисы** | Калькулятор подбора, каталог аналогов, база знаний, FAQ | Доп. ценность после запуска |
| **Модерация** | Все модерации и жалобы | Пока только ручная модерация через админку |
| **Аналитика** | Статистика, отчёты | Будущая фича |
| **Маркетинг** | Акции, купоны | Будущая фича |
| **Лояльность** | Баллы и скидки | Будущая фича |

## Категории бизнес-функций

### 1. Поиск и каталог товаров

**Основная задача:** Помочь покупателю найти нужную запчасть.

| Функция | Описание |
|---------|----------|
| **Поиск по VIN-коду** | Подбор совместимых запчастей по номеру автомобиля |
| **Поиск по артикулу** | Точный поиск по OEM-номеру или артикулу |
| **Поиск по названию** | Полнотекстовый поиск по наименованию |
| **Поиск по марке/модели** | Выбор из списка марок и моделей автомобилей |
| **Поиск по категории** | Навигация по категориям (двигатель, подвеска и т.д.) |
| **Фильтрация** | Фильтрация по цене, состоянию, наличию, региону продавца, рейтингу |
| **Сортировка** | Сортировка по цене, рейтингу продавца, дате добавления |

---

### 2. Профили и учетные записи

**Основная задача:** Управление пользователями.

| Функция | Описание |
|---------|----------|
| **Регистрация** | Создание учетной записи (email, пароль) |
| **Аутентификация** | Вход в систему через email и пароль |
| **Управление профилем** | Просмотр и редактирование личных данных (имя, телефон, адрес) |

---

### 3. Управление объявлениями (для продавцов)

**Основная задача:** Размещение и управление товарами.

| Функция | Описание |
|---------|----------|
| **Создание объявления** | Заполнение карточки товара (фото, описание, цена, наличие) |
| **Редактирование** | Изменение данных объявления (цена, описание, наличие) |
| **Архивация** | Скрытие объявления без удаления |
| **Продление** | Продление срока действия объявления |

---

### 4. Взаимодействие между участниками

**Основная задача:** Переписка между покупателями и продавцами.

| Функция | Описание |
|---------|----------|
| **Внутренний чат** | Переписка между покупателем и продавцом |

---

### 5. Оформление заказа и оплата

**Основная задача:** Безопасная покупка товара.

| Функция | Описание |
|---------|----------|
| **Добавление в корзину** | Сбор товаров для покупки |
| **Оформление заказа** | Пошаговое оформление заказа |
| **Безопасная сделка (эскроу)** | Резервирование средств, перевод после подтверждения получения (для MVP: упрощённая сделка без эскроу) |
| **Оплата картой** | Онлайн оплата через Сбербанк/Тинькофф (для MVP: базовая обработка без интеграций) |
| **Оплата при получении** | Наличные или банковский перевод |
| **Выбор доставки** | Выбор способа доставки (курьер, ТК, почта, самовывоз, без расчёта стоимости) |
| **Идемпотентность** | Защита от дублирования операций |

**Примечание для MVP:** Для MVP убраны эскроу и интеграция с банками. Используется упрощённая схема: пользователь выбирает способ оплаты (наличные при получении или онлайн оплата без интеграции).

---

### 6. Управление заказами

**Основная задача:** Отслеживание заказов.

| Функция | Описание |
|---------|----------|
| **Просмотр заказов** | Список заказов с фильтрацией по статусу |
| **Отслеживание статуса** | Визуализация текущего статуса заказа |
| **Отмена заказа** | Отмена заказа с указанием причины |
| **Возврат товара** | Оформление возврата и гарантии |

---

### 7. Рейтинги и отзывы

**Основная задача:** Прозрачность между участниками.

| Функция | Описание |
|---------|----------|
| **Оценка товара** | Выставление оценки по 5-балльной шкале |
| **Текстовый отзыв** | Написание отзыва |
| **Ответ продавца** | Возможность ответить на отзыв |
| **Рейтинг продавца** | Агрегация оценок покупателей |

---

### 8. Уведомления

**Основная задача:** Информирование пользователей.

| Функция | Описание |
|---------|----------|
| **Email уведомления** | Оповещения по электронной почте |
| **SMS уведомления** | Оповещения через SMS-шлюз |

---

## Резюме

### Ключевые бизнес-процессы

1. **Покупка товара:**
   - Поиск → Фильтрация → Просмотр → Чат с продавцом → Оформление заказа → Оплата → Доставка → Отзыв

2. **Продажа товара:**
   - Размещение объявления → Общение с покупателями → Оформление сделки → Доставка → Отзыв

3. **Модерация:**
   - Ручная проверка через админку
