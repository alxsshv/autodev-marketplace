# Порты сервисов в проекте autodev-marketplace

Данный документ содержит информацию о портах, используемых сервисами в проекте, разделённую на две категории: порты, проброшенные наружу (из Docker-сети на хост), и порты, используемые внутри Docker-сети для взаимодействия между контейнерами.

**Обозначения:**
- **Host Port** — порт, доступный с хост-машины (формат `host:container`)
- **Internal Port** — порт внутри Docker-сети (используется для межсервисного взаимодействия)
- **MVP сервисы (8)** — основные сервисы для релиза 1.0
- *Закомментированные сервисы* — сервисы, описанные в документации, но пока не развернуты в docker-compose.yaml

## Анализ конфликтов

**После анализа всех конфигурационных файлов (`docker-compose.yaml`, `application.yml`, `docker-compose-infrastructure.yaml`):**

- **Внешние порты (Host Ports):** Все порты, проброшенные на хост, уникальны и не дублируются. Зарезервированы диапазоны для будущих сервисов (8300-8499 для микросервисов).
- **Внутренние порты (Container Ports):** Все сервисы используют стандартные или логически обоснованные порты внутри своей сети. Даже если два сервиса используют одинаковый внутренний порт (например, `api-gateway` и `keycloak` на 8080), они изолированы в разных контейнерах, и конфликта не возникает, так как проброс на хост происходит на разные порты.

**Статус:** Система настроена корректно, конфликты портов отсутствуют. Все микросервисы получат уникальные порты в диапазоне 8300-8499.

## Рекомендации по развертыванию новых сервисов

1. **Для новых микросервисов:** Использовать порты по алфавиту в диапазоне 8300-8499
   - auth-service → 8300 (уже используется 8082)
   - catalog-service → 8300
   - user-service → 8322
   - и т.д.

2. **Для новых инфраструктурных сервисов:** Использовать свободные диапазоны 8500-8599, 9400-9999

3. **Для новых баз данных:** Проверять доступность портов 5432-5499

4. **Всегда обновлять этот документ** при добавлении новых сервисов в docker-compose.yaml

## Обновление конфигурации

При добавлении нового микросервиса:

1. Выбрать порт по алфавиту (см. таблицу выше)
2. Обновить `docker-compose.yaml` с пробросом порта:
   ```yaml
   new-service:
     ports:
       - "8323:8080"  # host:container
   ```
3. Обновить `application.yml` сервиса:
   ```yaml
   server:
     port: 8080  # internal port
   ```
4. Обновить `docs/ports.md` новой записью
