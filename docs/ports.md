# Порты сервисов в проекте autodev-marketplace

Данный документ содержит информацию о портах, используемых сервисами в проекте, разделённую на две категории: порты, проброшенные наружу (из Docker-сети на хост), и порты, используемые внутри Docker-сети для взаимодействия между контейнерами.

## Порты, проброшенные наружу (Host Ports)

Эти порты доступны с хост-машины и могут быть использованы для внешнего доступа к сервисам.

| Порт (Host) | Сервис | Назначение |
|-------------|--------|-----------|
| 8081 | api-gateway | Основной HTTP-порт API Gateway |
| 5435 | keycloak-database | PostgreSQL для подключения извне (например, через DBeaver) |
| 9188 | keycloak-database-exporter | Экспорт метрик PostgreSQL для Prometheus |
| 8090 | keycloak | HTTP-интерфейс Keycloak |
| 8443 | keycloak | HTTPS-интерфейс Keycloak |
| 9000 | minio | S3 API MinIO |
| 9001 | minio | Веб-консоль MinIO |
| 9095 | minio | Метрики MinIO для Prometheus |
| 6379 | redis | Redis для подключения извне |
| 9122 | redis-exporter | Экспорт метрик Redis для Prometheus |
| 9091 | prometheus | Веб-интерфейс и API Prometheus |
| 3100 | loki | HTTP-интерфейс и API Loki |
| 3200 | tempo | HTTP-интерфейс и API Tempo |
| 9080 | alloy | HTTP-интерфейс Alloy |
| 4317 | alloy | OTLP gRPC для трейсов и метрик |
| 4318 | alloy | OTLP HTTP для трейсов и метрик |
| 3000 | grafana | Веб-интерфейс Grafana |

## Анализ конфликтов

После анализа всех конфигурационных файлов (`docker-compose.yaml`, `application.yml`, `prometheus.yml`, `loki/config.yml`, `tempo.yaml`, `datasources.yml`) конфликтов портов не обнаружено.

*   **Внешние порты (Host Ports):** Все порты, проброшенные на хост (например, `8080:8080`, `8090:8080`, `9091:9090`), уникальны и не дублируются.
*   **Внутренние порты (Container Ports):** Все сервисы используют стандартные или логически обоснованные порты внутри своей сети (например, PostgreSQL на 5432, Redis на 6379). Даже если два сервиса используют одинаковый внутренний порт (например, `api-gateway` и `keycloak` на 8080), они изолированы в разных контейнерах, и конфликта не возникает, так как проброс на хост происходит на разные порты.

Система настроена корректно, и конфликты портов отсутствуют.
