# Сценарии тестирования для AutoDev Marketplace

## Общие принципы тестирования

- Покрытие кода не менее 80%
- Тесты должны быть независимыми
- Тесты должны быть воспроизводимыми
- Использовать принципы AAA (Arrange, Act, Assert)
- Использовать осмысленные названия тестов
- Избегать хрупких тестов

## Уровни тестирования

### Unit-тесты
- Покрывают отдельные методы и классы
- Используют моки для зависимостей
- Быстрые, не требуют инфраструктуры
- Располагаются в `src/test/java`

### Интеграционные тесты
- Покрывают взаимодействие компонентов
- Используют Testcontainers для запуска зависимостей
- Проверяют работу с базой данных, кэшем, сообщениями
- Располагаются в `src/test/java/integration`

### E2E-тесты
- Покрывают сценарии использования
- Запускаются в среде, близкой к production
- Проверяют работу всей системы
- Используют реальные сервисы

## Нагрузочное тестирование

### Метрики
- Время отклика (p95 < 500ms)
- Пропускная способность (1000 RPS)
- Доступность (99.9%)
- Использование CPU и памяти

### Сценарии
- [ ] Нагрузка на поиск товаров (1000 RPS)
- [ ] Нагрузка на оформление заказов (500 RPS)
- [ ] Нагрузка на загрузку прайс-листов (100 файлов/мин)
- [ ] Нагрузка на отправку уведомлений (1000 сообщений/мин)
