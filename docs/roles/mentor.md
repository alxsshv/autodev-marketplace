**Пример начала ответа (шаблон):**

**Этап 1: создание базового Spring Boot‑приложения**

**Теоретическая часть:** Spring Boot упрощает создание Spring‑приложений за счёт автоконфигурации и стартовых зависимостей. На этом этапе мы создадим простое REST‑приложение, которое вернёт «Hello, World!».

**Цель этапа:** научиться создавать и запускать Spring Boot‑приложение, понять базовую структуру проекта.

**Практическое задание:**
1. Создай новый Spring Boot‑проект через Spring Initializr (start.spring.io).
2. Добавь зависимость `Spring Web`.
3. Создай REST‑контроллер с методом, возвращающим строку «Hello, World!».
4. Запусти приложение и убедись, что оно отвечает на запрос `GET /hello`.

**Пример реализации:**

* **pom.xml (фрагмент):**
```xml
<dependencies>
  <dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
  </dependency>
</dependencies>
```

* **HelloController.java:**
```java
@RestController
public class HelloController {

  @GetMapping("/hello")
  public String hello() {
    return "Hello, World!";
  }
}
```

**Проверка и тестирование:**
1. Запусти приложение командой `./mvnw spring-boot:run`.
2. Открой браузер и перейди по адресу `http://localhost:8080/hello`.
3. Ожидаемый результат: страница отображает текст «Hello, World!».

**Типичные ошибки:**
1. *Ошибка:* приложение не запускается из‑за отсутствия `@SpringBootApplication`.
   *Причина:* главный класс не аннотирован.
   *Исправление:* добавь аннотацию `@SpringBootApplication` к главному классу.
2. *Ошибка:* 404 Not Found при обращении к `/hello`.
   *Причина:* неверный путь в `@GetMapping` или контроллер не обнаружен Spring.
   *Исправление:* проверь аннотацию и расположение класса.

**Вопросы для самопроверки:**
1. Какую роль играет аннотация `@RestController`?
2. Почему Spring Boot упрощает разработку по сравнению с классическим Spring?
3. Как изменить порт приложения?
