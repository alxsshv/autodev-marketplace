---

## 1. Цель проекта

Написать юнит-тесты и интеграционные тесты для микросервиса Auth Service с покрытием не менее 80%.

---

## 2. Функциональные требования

### FR-1. Юнит-тесты

**FR-1.1.** Написать юнит-тесты для `UserServiceImpl` с мокированием репозитория и маппера.

**FR-1.2.** Написать юнит-тесты для `UserController` с использованием MockMvc.

**FR-1.3.** Покрыть все методы сервиса и контроллера тестами.

**FR-1.4.** Покрыть сценарии:
- Успешное выполнение операций
- Обработка ошибок (UserNotFoundException)
- Валидация входных данных

**FR-1.5.** Использовать JUnit 5 и Mockito для тестирования.

### FR-2. Интеграционные тесты

**FR-2.1.** Написать интеграционные тесты с реальной базой данных через Testcontainers PostgreSQL.

**FR-2.2.** Написать интеграционные тесты с реальным Kafka через Testcontainers Kafka.

**FR-2.3.** Написать интеграционные тесты для проверки регистрации сервиса в Consul.

**FR-2.4.** Использовать Testcontainers для всех интеграционных тестов.

### FR-3. Критерии покрытия

**FR-3.1.** Покрытие юнит-тестами — не менее 80% для бизнес-логики.

**FR-3.2.** Все основные сценарии должны быть покрыты тестами.

**FR-3.3.** Тесты должны проходить при сборке: `./gradlew test`.

---

## 3. Нефункциональные требования

**NFR-1.** Время выполнения тестов не должно превышать 5 минут.

**NFR-2.** Тесты должны быть независимыми и работать в произвольном порядке.

**NFR-3.** Тесты должны быть детерминированными (не зависеть от внешних условий).

---

## 4. Технические требования

### 4.1. Зависимости

В `build.gradle.kts` должны быть добавлены:
- `org.springframework.boot:spring-boot-starter-test`
- `org.springframework.kafka:spring-kafka-test`
- `org.testcontainers:testcontainers`
- `org.testcontainers:junit-jupiter`
- `org.testcontainers:postgresql`
- `org.testcontainers:kafka`

### 4.2. Структура тестов

**Юнит-тесты:**
- `src/test/java/com/autodev/auth/service/UserServiceTest.java`
- `src/test/java/com/autodev/auth/controller/UserControllerTest.java`

**Интеграционные тесты:**
- `src/test/java/com/autodev/auth/integration/UserRepositoryIntegrationTest.java`
- `src/test/java/com/autodev/auth/integration/UserControllerIntegrationTest.java`
- `src/test/java/com/autodev/auth/integration/ConsulRegistrationTest.java`

---

## 5. Критерии приемки

**HC-1.** Юнит-тесты написаны для `UserServiceImpl` и `UserController`.

**HC-2.** Интеграционные тесты написаны с Testcontainers PostgreSQL.

**HC-3.** Интеграционные тесты написаны с Testcontainers Kafka.

**HC-4.** Интеграционные тесты проверяют регистрацию сервиса в Consul.

**HC-5.** Покрытие кода тестами — не менее 80%.

- Можно настроить генерацию отчета о покрытии кода (JaCoCo).
- Тесты должны работать локально и в CI/CD.
