# Технические задания для Auth Service

Этот каталог содержит технические задания для реализации микросервиса Auth Service.

## Список технических заданий

### TS-001: Подготовка проекта
**Приоритет:** Высокий  
**Оценка трудоемкости:** 2 дня

Создание структуры проекта, настройка зависимостей и конфигурации Spring Boot приложения.

**Что нужно сделать:**
- Создать директорию `services/auth-service`
- Настроить `build.gradle.kts` с необходимыми зависимостями
- Создать основной класс `AuthApplication`
- Настроить `application.yml` и `application-docker.yml`

---

### TS-002: Настройка базы данных
**Приоритет:** Высокий  
**Оценка трудоемкости:** 3 дня

Настройка PostgreSQL и миграций Liquibase для хранения данных о пользователях.

**Что нужно сделать:**
- Создать миграции Liquibase для таблицы `users`
- Создать JPA сущность `User`
- Создать репозиторий `UserRepository`

---

### TS-003: Создание DTO и маппинг
**Приоритет:** Средний  
**Оценка трудоемкости:** 1 день

Создание DTO классов для обмена данными и настройка маппинга.

**Что нужно сделать:**
- Создать классы `UserDto`, `CreateUserRequest`, `UpdateUserRequest`
- Создать enum `UserRoleDto`
- Настроить маппинг между сущностями и DTO

---

### TS-004: Сервисный слой
**Приоритет:** Высокий  
**Оценка трудоемкости:** 3 дня

Реализация бизнес-логики с кэшированием и транзакциями.

**Что нужно сделать:**
- Создать интерфейс `UserService`
- Реализовать методы с кэшированием и транзакциями
- Настроить Redis для кэширования

---

### TS-005: REST API
**Приоритет:** Высокий  
**Оценка трудоемкости:** 2 дня

Создание REST API для управления пользователями.

**Что нужно сделать:**
- Создать контроллер `UserController`
- Реализовать эндпоинты для CRUD операций
- Настроить валидацию и обработку ошибок

---

### TS-006: Интеграция с Keycloak
**Приоритет:** Высокий  
**Оценка трудоемкости:** 3 дня

Настройка интеграции с Keycloak через OAuth2/OpenID Connect.

**Что нужно сделать:**
- Настроить Spring Security как OAuth2 Resource Server
- Настроить валидацию JWT токенов
- Настроить проверку ролей пользователей

---

### TS-007: Интеграция с Kafka
**Приоритет:** Средний  
**Оценка трудоемкости:** 2 дня

Настройка асинхронной коммуникации через Apache Kafka.

**Что нужно сделать:**
- Создать классы событий (`UserCreatedEvent`, `UserUpdatedEvent`, `UserDeletedEvent`)
- Настроить Kafka Producer для отправки событий
- Настроить Kafka Consumer для получения событий

---

### TS-008: Docker и инфраструктура
**Приоритет:** Высокий  
**Оценка трудоемкости:** 2 дня

Настройка контейнеризации и интеграция в инфраструктуру.

**Что нужно сделать:**
- Создать `Dockerfile` для сервиса
- Обновить `docker-compose.yaml` с сервисом `auth-service`
- Создать `auth-database` (PostgreSQL)

---

### TS-009: Тестирование
**Приоритет:** Высокий  
**Оценка трудоемкости:** 3 дня

Написание юнит-тестов и интеграционных тестов.
